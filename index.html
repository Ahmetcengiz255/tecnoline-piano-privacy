# Privacy Policy – Tecnoline Piano Studio **Effective Date:** October 13, 2026 Tecnoline Piano Studio is a piano learning and music creation application developed by Tecnoline. **1. Personal Information** Tecnoline Piano Studio does not require users to create an account or provide personal information to use its features. **2. Data Storage** Lesson progress, performance results and saved musical compositions are stored locally on the user's device. The application does not operate its own server for collecting this information. Depending on the device's Android backup settings, some application data may be included in system backups. **3. Internet and Advertising** The application is designed to work offline and does not include third-party advertising or analytics services. **4. File Export** Users may export their compositions as MIDI or PDF files. Files are saved to locations selected by the user. **5. Children's Privacy** The application does not knowingly collect personal information from children. **6. Data Security** The application uses local device storage. Users should protect their devices and exported files using appropriate security measures. **7. Changes to This Policy** This privacy policy may be updated when the application's features or data practices change. **8. Contact** For privacy-related questions, please contact: Tecnoline **Email: tecnolineapp@hotmail.com
